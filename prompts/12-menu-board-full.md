## Notes

Supersedes the generic-wordmark version in `11-cafe-detail-shots.md`. The user asked for the
real menu and the real object placement after that substitution was flagged, so this run
carries the actual branding, items and prices as photographed.

**Transcribe, don't summarise.** The whole board is written out line by line — every item,
every price, every tasting note, and which colour and weight each line is set in. Asking for
"a menu with drink names and prices" produces plausible invented type; dictating the exact
strings produced all three columns correct on the first attempt, dual prices ("3.95/4.45")
included. This is the same lesson as the pastry cards, at about four times the density.

**Object placement is a left-to-right walk.** Listing the counter objects in the order they
appear across the frame, each anchored to a neighbour ("just below and behind it", "at the
far right edge, partly cut off"), held the arrangement. Listing them as an unordered set
does not.
